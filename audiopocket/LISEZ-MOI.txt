AUDIOPOCKET — installation sur iPhone

1. Publiez tous les fichiers du dossier dans un dépôt GitHub.
2. Dans GitHub : Settings > Pages > Deploy from a branch > main / root.
3. Ouvrez l’URL Pages publiée dans Safari sur l’iPhone.
4. Touchez Partager > Sur l’écran d’accueil.

Limites :
- L’application ne télécharge pas directement le son d’une URL YouTube.
- Elle convertit un fichier vidéo/audio déjà accessible sur l’appareil et que vous avez le droit de convertir.
- FFmpeg est chargé depuis un CDN ; connexion Internet nécessaire au premier lancement.
- Les gros fichiers peuvent échouer sur Safari iOS en raison de la mémoire disponible.
- Dans la feuille de partage iOS, choisissez « Enregistrer dans Fichiers ».
